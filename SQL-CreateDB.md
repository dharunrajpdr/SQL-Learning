# 📚 SQL — CREATE DATABASE

## 🔹 What is `CREATE DATABASE`?

`CREATE DATABASE` is used to **create a new database**.

A database is a container that stores **tables and their data**.

---

## 📝 Syntax

```sql
CREATE DATABASE database_name;
## 🗃️ Example

Imagine a college wants to store student information.

Create a database for the college.

⭐ SQL Query
CREATE DATABASE CollegeDB;

This creates a database named CollegeDB.
