# SQL Learning

A beginner-friendly SQL learning repository covering core SQL concepts, commands, clauses, and advanced topics with simple explanations and examples.

This repository is designed for students, developers, and anyone who wants to understand SQL step by step.

## Why this repository?

SQL is essential for working with relational databases such as MySQL, PostgreSQL, SQL Server, and Oracle. This repo helps you learn:

- SQL basics and syntax
- Data retrieval and manipulation
- Table creation and constraints
- Joins and subqueries
- Aggregations and window functions
- Transactions, triggers, views, and indexes

## Recommended learning path

1. Start with [docs/SQL-Basics.md](docs/SQL-Basics.md)
2. Learn the core commands in [docs/SQL-Commands.md](docs/SQL-Commands.md)
3. Understand clauses and filtering in [docs/SQL-Clauses.md](docs/SQL-Clauses.md)
4. Practice table design using [docs/SQL-CreateTable.md](docs/SQL-CreateTable.md) and [docs/SQL-Constraints.md](docs/SQL-Constraints.md)
5. Move into joins, functions, and subqueries
6. Explore advanced topics like transactions, triggers, indexes, and window functions

## How to use this repository

- Open the Markdown files in the `docs` folder.
- Read the examples carefully.
- Try the SQL queries in a local database or SQL editor such as:
  - MySQL Workbench
  - pgAdmin
  - SQL Server Management Studio (SSMS)
  - SQLite Browser
  - DBeaver
