# 📚 SQL — Introduction

## 🔹 What is SQL?

> **SQL = Structured Query Language**

SQL is a language used to **communicate with a database**.

We use SQL to **store, retrieve, update, and delete data** from a database.

---

## 🗃️ Example

Imagine a company has an `employees` table:

| ID | Name | Department | Salary |
|:--:|:-----|:-----------|-------:|
| 1 | Arun | IT | ₹50,000 |
| 2 | Ravi | HR | ₹40,000 |
| 3 | Priya | IT | ₹60,000 |

---

## 🎯 Requirement

> **"Show me all employees."**

### ⭐ SQL Query

```sql
SELECT * FROM employees;
